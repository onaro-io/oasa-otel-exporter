# Code of conduct

This project follows the [CNCF Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md), the same code used by OpenTelemetry.

In short: be respectful, assume good faith, and keep discussion focused on the work. Harassment, personal attacks, and discriminatory language are not acceptable in issues, pull requests, or any other project space.

To report a concern, email **hello@onaro.io** with "Code of conduct" in the subject. Reports are handled confidentially by the maintainers. If a maintainer is involved, you can also contact the CNCF at conduct@cncf.io.
